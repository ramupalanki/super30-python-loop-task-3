# super30-python-loop-task-3

This folder contains the Python programs split into independently executable `.py` files.

## Programs

1. `01_transactions.py` - total transaction value without `sum()`
2. `02_transaction_high_low.py` - highest and lowest transaction without `max()`/`min()`
3. `03_average_temperature.py` - average temperature
4. `04_student_marks.py` - count students by marks range
5. `05_login_system.py` - login with maximum 3 password attempts
6. `06_products.py` - products costing more than ₹2,000
7. `07_input_numbers.py` - accept 10 numbers into a list
8. `08_character_frequency.py` - character frequency without `Counter`
9. `09_second_largest.py` - second-largest without `sort()`
10. `10_palindrome.py` - palindrome check using loops
11. `11_number_pattern.py` - number pattern using nested loops
12. `12_atm.py` - basic ATM simulation organized with functions

## Run

From this folder, run any program with:

```bash
python filename.py
```

For example:

```bash
python 12_atm.py
```
